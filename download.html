发布到 GitHub 前只需改 1 个配置

打开 assets/js/config.js，把：

githubRepo: "YOUR_GITHUB_USERNAME/FreeDoc"

改成你的实际 GitHub 仓库，例如：

githubRepo: "zirujiang/FreeDoc"

然后在 GitHub Releases 上传安装文件，文件名保持与 downloadAsset 一致，网站下载按钮就会自动指向最新版。

建议 Release 文件

  • FreeDoc_Setup_1.3.13.exe — 给普通用户安装。
  • 可选：源码 ZIP / SHA256 校验值 / Release Notes。
正式公开前，建议先在另一台没有 Python 的 Windows 电脑上验证安装、启动、卸载、OCR 和 Office 转换。
