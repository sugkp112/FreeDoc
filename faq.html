FAQ

常见问题

FreeDoc 是免费的吗？

目前定位为免费的本地文档工具箱。未来如果增加 Pro 或企业功能，应明确区分新增高级功能与现有免费核心功能。

文件会上传服务器吗？

桌面版核心 PDF / Office / OCR 工作流以本地处理为目标，不要求上传私人文件到 FreeDoc 网站。

支持哪些系统？

当前主要面向 64-bit Windows 10 / 11。

必须安装 Python 吗？

正式 Standalone 安装包应把 Python Runtime 与需要的组件一起打包，普通用户不需要单独安装 Python。

Office 转 PDF 需要 Office 吗？

FreeDoc 优先使用 Microsoft Office Automation；没有 Office 时可根据安装情况使用 LibreOffice fallback。

扫描 PDF 可以搜索文字吗？

可以通过 OCR 功能给扫描 PDF 加入可搜索文字层。实际效果取决于扫描质量、语言和本地 OCR 引擎。

在哪里下载最新版？

建议通过 FreeDoc 官网下载，安装文件由 GitHub Releases 托管。
